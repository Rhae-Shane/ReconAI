## One sentence

An agent that takes a messy multi-source finance batch (≥50 records; ours is **81**), reconciles it across gateway / bank / ERP / GST, settles, forecasts cash, maps tax, and ships a **Close Report** with match rate + precision/recall + an **honest exception list** — nothing silently dropped.

## The track bar

> Throughput plus measured accuracy plus an honest exception list. One cherry-picked match proves nothing.

ReconAI was designed so that bar is **engineered in**, not bolted on: deterministic matching first, LLM only on residual ambiguity, ground-truth labels for precision/recall, and every unresolved row filed with a structured reason code — never silently dropped.

## Why it exists (the bar)

The track’s “why now” is: **verification, not generation**, is the bottleneck. Reconciliation / settlement / forecasting are still manual.

| Deliverable | How you prove it |
| --- | --- |
| **Throughput** | Full 81-record close in well under a second; scalable via BullMQ |
| **Measured accuracy** | Ground-truth labels → match rate, precision, recall |
| **Honest exceptions** | Every unresolved row gets a reason code + rationale |

### Locked audited baseline (tests enforce this)

```
records=81 · sources=4 · matched=66 · partial=2 · unresolved=13
resolved=81.48% · exceptions=15 · precision=1.00 · recall=1.00
```
