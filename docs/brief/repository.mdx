Local checkout folder name may be `AI Finance Controller/`; GitHub repo is **ReconAI**.

## 4.1 Why two packages?

| Package | Role |
| --- | --- |
| `harness/` (`controller-harness`) | Accuracy-critical math; Vitest without Next/Prisma/React |
| `app/` (`reconai`) | Thin dashboard + APIs + ops; imports `file:../harness` |

**Split on purpose:** accuracy-critical math lives in `harness/` so Vitest can gate it without Next/Prisma/React. The app is a thin UI/API shell. Dashboard churn cannot silently break settlement math. CI gates the engine independently.
