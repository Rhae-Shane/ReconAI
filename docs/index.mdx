## What is ReconAI?

ReconAI is a settlement reconciliation controller for Razorpay merchants.

It reconciles payments, settlements, and invoices the way a finance team actually does:

- **Match** gateway, bank UTR, ERP, and GST lines through a deterministic pipeline
- **Settle** matched groups with explicit netting math (gross − fee − tax − refund + adjustment)
- **Forecast** short-horizon cash from matched settlement lags
- **Close** with an honest exception list — never silent drops

Deterministic matching runs first (exact → normalized → netting → fuzzy). An AI resolver is used only for residual ambiguity.

## Who is it for?

1. **Finance ops teams** closing books across gateway, bank, ERP, and tax lines
2. **Razorpay merchants** who need reproducible matches and a reviewable exception ledger
3. **Accountants and controllers** who need confidence, reason codes, and an auditable close report

## Design pillars

| Pillar | What |
| --- | --- |
| **Deterministic-first** | Reproducible matches; confidence + reason on every decision |
| **Measured accuracy** | Ground-truth labels → match rate, precision, recall |
| **Honest exceptions** | Structured reason codes; zero silent drops |
| **Graceful ops** | Redis / OpenAI / Razorpay optional; in-process fallback |

Every assertion (CLI, API, agent tool) flows through one audited funnel: **FinanceCore**.

## Core primitives

| Concept | Description |
| --- | --- |
| **FinRecord** | Normalized finance row — source, kind, refs, amount in paise, value date |
| **MatchGroup** | Set of records judged to be one underlying money movement |
| **MatchType** | Decision label: `EXACT`, `NORMALIZED`, netted types, `PARTIAL`, `FUZZY`, `AI_RESOLVED`, `UNRESOLVED` |
| **ReasonCode** | Why a row is unresolved: `NO_KEY`, `AMOUNT_MISMATCH`, `PARTIAL_FLAP`, `DATE_SKEW`, `LOW_CONFIDENCE`, `DUPLICATE`, … |
| **CloseReport** | Terminal deliverable of a close run — totals, breakdown, exceptions, precision/recall |
| **FinanceCore** | Single audited pipeline: ingest → reconcile → judge → settle → forecast → tax → exceptions → close |
